Basic Headers & Text

Structure a document with headings, emphasis and paragraphs.

Headings Use one to six # symbols. One # is the page title.

# Heading 1
## Heading 2
### Heading 3

Emphasis - italic renders as italic - bold renders as bold - strike renders as strike

Leave a blank line between paragraphs to start a new one.
