MDX (Markdown with Components)

Use JSX components inside Markdown.

import Alert from './Alert'

# Hello MDX

<Alert type="info">Components render inline.</Alert>

export const year = 2026

MDX is common in React-based tools such as Docusaurus, Astro and Next.js.
